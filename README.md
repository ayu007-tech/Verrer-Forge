# Verrar Forge — website starter

A premium, responsive Next.js company website starter for Verrar Forge.

## Before publishing
1. Confirm that the Verrar Forge name and intended domain are legally available.
2. Replace `hello@verrarforge.com` in `app/page.tsx` with a verified business email.
3. Review every service against the team's actual delivery capacity.
4. Confirm project descriptions and statuses; do not imply these are paid client engagements.
5. Add real project screenshots, demo links, repository links and privacy/legal pages.
6. Install dependencies and run the production build.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## Deploy
Import the repository into Vercel or another Next.js-compatible host. Configure the verified domain after ownership and DNS are confirmed.
